# Archi Agent v0.3.0-alpha.4 — pre-release notes

The published `v0.3.0-alpha.3` tag and assets remain unchanged. This release
contains UX2 and uses the preserved VSIX identified below.

## Changes since v0.3.0-alpha.3

- Local, offline OCR for scanned PDF pages uses bundled Polish and English language data.
  PDF conversion offers **Auto OCR**, **No OCR**, and **OCR all pages**. Auto keeps readable
  text and recognizes pages without text. DOCX and XLSX do not show an OCR choice.
- Conversion reports progress and supports **Cancel** without opening a partial Markdown
  document. Markdown page headings mark OCR and blank pages and preserve page order.
- The self-contained VSIX bundles the OCR engine, WASM, PL/EN models and canvas bindings.
  It needs no runtime download, repository checkout, npm, separate Node.js, model provider,
  Knowledge Pack, or network connection for conversion.

Existing CL1 limits remain: 50 MiB input, 8 MiB Markdown output, 300 PDF pages and a
120-second text conversion deadline. Office ZIP and XLSX limits remain in the
[extension guide](../vscode-extension.md#known-limitations). OCR allows 20 recognized pages,
a 10 MP rendered canvas, a 16 MP embedded image, and a 300-second deadline once a page
without text becomes an OCR candidate. PDF layout and tables are not reconstructed.
