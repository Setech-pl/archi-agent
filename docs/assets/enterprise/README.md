# Enterprise diagram renders

These images are deterministic PlantUML renders, not application screenshots. Sources were generated
by the candidate runtime from `examples/retail-checkout/architecture/enterprise-views.json`.
`provenance.json` records semantic source/projection digests and generated PlantUML hashes.
PlantUML 1.2026.6, Temurin Java 21 and the built-in Smetana layout rendered SVG/PNG locally.
No external PlantUML server or model was used. Original `.puml` files accompany the images.
