# Tutoriale

Zacznij od [Retail Checkout](../../examples/retail-checkout/START-HERE.pl.md): pierwszy deterministyczny Verify Flow, provenance, cztery diagramy, odmiana polskiej nazwy i oryginalna para ART1. Następnie [Mission Control](../../examples/mission-control/START-HERE.pl.md): rzeczywiste procesy obu kierunków MCP, CLI, review dokumentów i nowy pack oraz opcjonalny OCR Full.

[Publiczne ZIP-y i instalatory](https://github.com/Setech-pl/archi-agent/releases/tag/v0.3.0-alpha.8) · [Historyczne dowody DEMO1](https://github.com/Setech-pl/archi-agent/blob/d723af09dacc71746a82c0fddcad97beb2cece8e/docs/demo1-verification.md). Każdy ZIP zawiera komplet instrukcji PL/EN i gotową syntetyczną wiedzę. VSIX wymaga VS Code 1.91+, bez repo/npm/Node. Opcjonalne CLI/MCP wymaga Node 22.12+. Pierwszy Verify Flow na PlantUML nie wymaga modelu; generowanie/proza/ekstrakcja korzystają z Twojego providera. Włącz dokładnie jeden profil Core/Full.

[Cztery widoki enterprise](capability-map.md): katalog Retail alpha.8 obsługuje Capability Map, Capability–Application Map, Value Stream i Application Landscape. Renderowanie nie wymaga providera; budowanie, review i aktualizację opisuje [instrukcja użytkownika](user-guide.md#value-stream-i-application-landscape).

Ten sam katalog udostępnisz przez osobny serwer wiedzy enterprise i odczytasz przez CLI według kompletnej sekcji Capability Map w guide CLI/MCP. Konfiguracja LLM nie jest potrzebna.
