# Archi Agent v0.3.0-alpha.3

**Status:** prerelease notes for the final `alpha.3` VSIX. The owner confirmed smoke PASS for
this exact VSIX with SHA-256 `7b9cc84b9ce7070abee33fe08cc19636efe2c2271d9aea3f4cd6bd0a1bad1056`.
The owner previously reported PASS for large PDF, XLSX, and Word conversion in the separate
`alpha.2` candidate. No individual UI cases were specified for the final `alpha.3` smoke.

## Changes since v0.3.0-alpha.1

- Local PDF, DOCX, and XLSX conversion accepts files up to 50 MiB.
- The Markdown result is limited to 8 MiB, conversion to 120 seconds, and text-layer PDF to
  300 pages. Office ZIP limits are 1000 entries, 100 MiB inflated total, 25 MiB per entry,
  and a 100:1 compression ratio.
- XLSX limits are 40 sheets, 20000 rows, 150 columns, and 250000 cells. Worksheet XML,
  shared strings, styles, cell addresses, and sparse grids are checked before the spreadsheet
  parser runs. Cancel and failure return no partial document.

Conversion remains local and needs no model, account, network connection, or Knowledge Pack.
DOC and XLS, scanned-PDF OCR, and layout reconstruction remain unsupported. This release does
not include MCP or VS Code Chat.

After publication, download the VSIX and its SHA-256 file from the GitHub prerelease. Verify the
checksum, then use **Extensions → … → Install from VSIX…** in VS Code. The extension contains its
runtime and conversion worker; it needs no repository checkout, npm, or separate Node.js install.
